# 0. Transmission — reference project

**Status:** the project already underway. Specified elsewhere; this file exists so the
portfolio table has an anchor, not to re-derive it.

It scores well on all four axes, which is why it goes first. Everything else in
`ideas/` is a year-two or year-three candidate measured against it.

## Why it is the baseline

Two things this project establishes that the others inherit:

1. **The acquisition muscle.** Babysitting dozens of state and regional sources that
   change without notice is the actual company. Whichever idea comes second should
   reuse that operational spine rather than starting a new one.
2. **The proof that a derived number sells.** Once one buyer has paid for a computed
   field rather than a lookup, the second sale is a variation on a pitch that worked,
   not a new argument.
